# Smaller Gallery Direct Version B packages

1. Unzip Gallery-Version-B-Code.zip.
2. Unzip Gallery-Mirror-Images.zip and the three Gallery-Art-Images ZIPs.
3. Move the files inside Mirror-images into gallery-direct-version-b/dist/assets/gallery-mirrors/.
4. Move the files from Art-images-1, Art-images-2 and Art-images-3 into gallery-direct-version-b/dist/assets/gallery-art/.

Upload the contents of gallery-direct-version-b to GitHub, keeping the folders intact. The main README has upload and local preview instructions.
